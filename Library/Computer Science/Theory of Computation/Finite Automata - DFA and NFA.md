# Finite Automata - DFA and NFA

> **Summary:** Deterministic and nondeterministic finite automata accept exactly the regular languages. Only the page on finite-state automata and regular languages (3.6) and the non-regular-languages page (3.7) were read; the sections that define DFA/NFA (3.4, 3.5 in the chapter index) were not.

## What it is

Coverage note: the book pages read are 3.1, 3.6 and 3.7. Sections 3.2 to 3.5 (regular expressions, using them, FSA, NFA) were opened only as an index and NOT read. So formal definitions of the DFA/NFA tuples are not sourced here.

What the read pages state:
- Theorem 3.3: every language generated by a regular expression is recognised by an NFA (structural induction, using epsilon-transitions).
- Theorem 3.4: every language accepted by a DFA or an NFA is generated by a regular expression (an R(i,j,k) construction).
- Together: regular expressions, NFAs and DFAs define the same class of languages (see [[Regular Expressions and Regular Languages]]).
- For DFAs, complement is obtained by swapping accepting and non-accepting states; this does not work for NFAs (Theorem 3.5 discussion).

## How it works

A DFA reads a string symbol by symbol and moves between a finite set of states; it accepts if it ends in an accepting state (gloss, unsourced: standard description, definitions not read in the book). An NFA may have several possible moves per symbol (and epsilon-moves) and accepts if some run accepts (gloss, unsourced).

## Key terms

> **DFA**: deterministic finite automaton (gloss, unsourced beyond the theorems above).

> **NFA**: nondeterministic finite automaton; may use epsilon-transitions (the use in Theorem 3.3 is sourced).

## Example

Own illustration (not from a source): a DFA simulator sketch.

```python
def run_dfa(delta, start, accepting, word):
    state = start
    for ch in word:
        state = delta[(state, ch)]
    return state in accepting

# even number of 'a's over {a, b}
delta = {("e","a"):"o", ("o","a"):"e", ("e","b"):"e", ("o","b"):"o"}
print(run_dfa(delta, "e", {"e"}, "abaa"))  # False (three a's)
```
