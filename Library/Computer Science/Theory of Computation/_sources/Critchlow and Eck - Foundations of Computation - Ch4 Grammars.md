Same textbook as the Ch3 note: open university text, level A. Caveat: it never mentions the Chomsky hierarchy or context-sensitive grammars on the pages read; use the Chappell and Chu notes for that.

## Extracted points

- Subtopic 3: parsing = finding a derivation of a string from grammar G, or showing none exists (membership test). Parse tree: start symbol is root, terminals are leaves; many derivations share one tree; left derivations correspond one-to-one with parse trees (Theorem 4.5). Ambiguous grammar = some string has more than one left derivation (example x + y * z).
- Parsing algorithms named: LL(1) (top-down, builds left derivation, one-symbol lookahead); LR(1) (bottom-up shift/reduce, builds right derivation in reverse; the claim "widely used in compilers" was in the fetch summary and is unverified against the page text); some unambiguous grammars are LR(1) but not LL(1).
- PDA = finite automaton with a stack, tuple (Q, Sigma, Lambda, q0, delta, F); accepts w if it can read all of w and finish in a state of F with an empty stack (this book's acceptance convention; other texts differ).
- Theorem 4.6: a language is context-free iff some PDA accepts it; the book proves only the grammar -> PDA direction.
- Nondeterminism matters for PDAs: there are context-free languages that are not deterministic context-free (unlike DFA/NFA).
- Subtopic 4 (partial): general grammars have rules u -> x with u any string containing a non-terminal; CFGs are the special case. The languages they generate are exactly the recursively enumerable languages.
