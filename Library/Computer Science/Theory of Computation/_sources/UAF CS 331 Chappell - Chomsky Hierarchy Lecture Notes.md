# UAF CS 331 Chappell - Chomsky Hierarchy Lecture Notes

## Why it is reliable (or not)

University course lecture notes by a faculty member; level B. Programming-languages course, so the hierarchy is a short aside, emphasis on regular and context-free (lexing, parsing). Context-sensitive row is thin ("we don't care much"). Containment stated, strictness not argued on the page.

## Extracted points

- Subtopic 4: Type 3 regular (productions A -> epsilon, A -> b, A -> bC) / finite automaton; Type 2 context-free (single nonterminal on LHS) / nondeterministic pushdown automaton; Type 1 context-sensitive (str1 A str2 -> str1 any str2) / linear bounded automaton; Type 0 recursively enumerable (arbitrary grammar) / Turing machine.
- "Each of the above categories is contained in the next." Some languages are not recursively enumerable at all.
