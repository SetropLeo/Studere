## Extracted points

- Subtopic 1: alphabet = finite non-empty set of symbols; string = finite sequence of symbols; language over Sigma = subset of Sigma*; uncountably many languages over any alphabet (so more languages than programs, since programs are countable; the countability link is not on this page).
- Subtopic 2: Theorem 3.3 regex -> NFA (structural induction, epsilon-transitions); Theorem 3.4 DFA/NFA -> regex (R(i,j,k) construction); together regex, NFA, DFA define the same class (the page does not use the name "Kleene's theorem").
- Theorem 3.5 closure: union, concatenation, complement, Kleene star, intersection. Complement by swapping accepting states works for DFAs, not NFAs. Intersection via a pairing construction on 3.6 (states are pairs of M1 and M2 states, Q1 x Q2; accept only when both accept); the page does not use the name "product construction" (standard term, own gloss).
- Theorem 3.6 pumping lemma for regular languages; Theorem 3.7 proves {a^n b^n | n >= 0} non-regular by choosing a^N b^N. {a^p | p prime} is named non-regular but not proved.

## Relevant excerpts

> "In formal language theory, an alphabet is a finite, non-empty set." (3.1)

> "A language over an alphabet Sigma is a subset of Sigma*." (3.1; Sigma rendered as in the page's LaTeX)

> "Every language generated by a regular expression can be recognized by an NFA." (Theorem 3.3, 3.6)

> "Every language that is accepted by a DFA or an NFA is generated by a regular expression." (Theorem 3.4, 3.6)

> "The intersection of two regular languages is a regular language." (Theorem 3.5, 3.6)
