## Extracted points

- Semigroup = set with associative binary operation; monoid = semigroup with identity; group = monoid with inverses (hierarchy magma > semigroup > monoid > group). Matches Haskell docs (semigroup/monoid) and ADS (monoid/group).
- Examples: strings under concatenation (monoid with empty string); positive integers under + (semigroup, not monoid).
- Claim to confirm: finite semigroups important in theoretical CS since the 1950s; link to finite automata via the syntactic monoid; transformation semigroups model state machines.
- Lattice: poset where every pair has a join and a meet; a semilattice has only one of them; lists "abstract interpretation", "semantics of programming languages" as applications (no details). 
- Gap: no confirmed source yet for lattices in dataflow/static analysis (candidate sources found but unreadable, see MOC gaps).
