# Open Logic Project Sets Relations Functions (Zach)

## Why it is reliable (or not)

Open (CC BY) university-level logic/set theory textbook by a team led by a professional logician; hosted on LibreTexts. Philosophy/logic orientation rather than programming. The page read is the Relations section (1.02); it does not cover equivalence classes or partitions. Fetched through a summarizing tool, so recheck quotes before verbatim use.

## Extracted points

- A relation on A is a way of relating elements of A; formally a set of ordered pairs.
- Equivalence relation = reflexive, symmetric, transitive.
- Preorder = reflexive + transitive; partial order = preorder that is also antisymmetric.
- Linear order = partial order that is also connected (the page uses "linear order", not "total order").

## Relevant excerpts

> "A relation that is reflexive, symmetric, and transitive is called an equivalence relation."

> "A preorder which is also anti-symmetric is called a partial order."

> "A partial order which is also connected is called a linear order."
