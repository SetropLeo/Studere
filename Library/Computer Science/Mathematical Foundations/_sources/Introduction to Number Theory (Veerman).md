# Introduction to Number Theory (Veerman)

Page read: section 1.1 Divisors and Congruences.

## Why it is reliable (or not)

Open university textbook (CC BY-NC). Good for formal definitions; this section does not mention Euclid's algorithm or cryptography, so it supports only the definitions. Date not shown.

## Extracted points

- Definition 1.1: a divides b (a|b) when b = a*c for some integer c.
- Definition 1.2: gcd(a, b) is the largest integer dividing both a and b (always >= 1).
- Definition 1.5: a and b are congruent mod m when m divides b - a.
- Only applied example: clock arithmetic (mod 12 or 24).
