# Milewski - Free Monoids

## Why it is reliable (or not)

Milewski is a well-known programmer/author of the open book Category Theory for Programmers (CC BY-SA 4.0 per search snippet, not verified on the page). Level B (expert blog). Haskell-oriented; assumes some category theory, so partly above beginner level. Use only for programming context, not as sole basis.

## Extracted points

- A monoid can be seen as a set with a binary "multiplication", a unit element and associativity, or as a category with a single object.
- In Haskell: type class with `mempty` and `mappend`; unit and associativity laws "cannot be expressed in Haskell and must be verified by the programmer" (tool paraphrase of the page).
- Lists are monoids: `[]` as unit and `(++)` (concatenation) as operation; a list type is the free monoid generated by its element set.
- Natural numbers under multiplication form a monoid that is not free (2*3 = 6 identifies different products), unlike lists ([2]++[3] = [2,3]).
