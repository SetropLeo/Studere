# RFC 5280 - X.509 PKI profile

## Why it is reliable (or not)

IETF Standards Track, the normative profile of X.509 for the Internet. Only the first 100,000 of 378,424 characters were read (covering the overview, certificate structure, path validation, CRL). Updated by later RFCs (e.g. on algorithms); OCSP is in RFC 6960 (not read).

## Extracted points

- X.509 v3 certificate: signed to-be-signed part, signature algorithm, signature; fields version, serial, issuer, subject, validity, public key, extensions (critical flag).
- CA certificates (cross, self-issued, self-signed) vs end entity certificates.
- Path validation: chain from end-entity to trust anchor checking signatures, validity, name chaining, constraints.
- Revocation via signed CRLs of serial numbers; latency depends on issue frequency; OCSP is an online alternative.

## Relevant excerpts

> "This memo profiles the X.509 v3 certificate and X.509 v2 certificate revocation list (CRL) for use in the Internet." (abstract)
