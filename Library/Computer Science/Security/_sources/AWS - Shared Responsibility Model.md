# AWS - Shared Responsibility Model

## Why it is reliable (or not)

Official provider documentation, authoritative for AWS but vendor-specific, and the concept is also published by Azure and Google (not opened; a second, independent provider source is a gap). Marketing-page tone. Rated B as a vendor page.

## Extracted points

- Security "of" the cloud: AWS (hardware, software, networking, facilities).
- Security "in" the cloud: customer (data, configuration, guest OS depending on service: EC2 vs S3).
- Responsibilities shift with the service model.

## Relevant excerpts

> "AWS is responsible for protecting the infrastructure that runs all of the services offered in the AWS Cloud."

> "Customers are responsible for managing their data (including encryption options)."
