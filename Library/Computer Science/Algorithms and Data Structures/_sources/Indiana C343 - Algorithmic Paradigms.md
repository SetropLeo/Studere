# Indiana C343 - Algorithmic Paradigms

## Why it is reliable (or not)

University course page, Level B. No author or date on the page. Does not describe brute force or backtracking. Short; supports only the definitions and contrasts below. Search results also surfaced USC CSCE750 and TAMU CSCE411 PDFs on optimal substructure/greedy-choice (not opened, so not used).

## Extracted points

- Greedy: "build up a solution incrementally, myopically optimize some local criteria"; not always optimal, but optimal for activity selection and fractional knapsack.
- Divide and conquer: "break up a problem into non-overlapping subproblems, solve subproblems independently"; example quicksort.
- Dynamic programming: overlapping subproblems, "build up solutions to larger and larger subproblems"; examples Fibonacci, 0-1 knapsack, edit distance.
