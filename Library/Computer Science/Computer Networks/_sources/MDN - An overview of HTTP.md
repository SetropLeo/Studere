# MDN - An overview of HTTP

## Why it is reliable (or not)

MDN is the reference web-platform documentation, maintained collaboratively with browser vendors. Level A/B for web concepts (documentation, not the normative RFC 9110).

## Extracted points

- (7) HTTP is client-server, request/response messages, stateless (cookies give sessions), application-layer protocol over TCP or TLS over TCP.

## Relevant excerpts

> "HTTP is stateless: there is no link between two requests being successively carried out on the same connection."
> "HTTP cookies allow the use of stateful sessions."
> "an application layer protocol that is sent over TCP, or over a TLS-encrypted TCP connection, though any reliable transport protocol could theoretically be used."
